# Корень

Корневое правило всего проекта — `ПРАВИЛО.md` рядом с этим файлом. Перед любой работой прочитать его целиком.

Отдельное общее правило подпроектов — `DuckTales/ПРАВИЛО.md`. У каждого подпроекта ещё своё `ПРАВИЛО.md` в своей папке.

При переключении на подпроект читать правило этого подпроекта и не смешивать его с правилом другого: у одного одно, у другого другое.
